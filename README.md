# 💱 Conversor de Moedas em TypeScript

Um aplicativo de linha de comando (CLI) interativo e eficiente desenvolvido em **TypeScript** e **Node.js** que consome taxas de câmbio em tempo real de uma API externa para converter valores entre diferentes moedas.

---

## 🚀 Funcionalidades

- **Cotações em tempo real:** Integração com a ExchangeRate-API.
- **Interface Interativa:** Menu dinâmico no terminal utilizando Inquirer.js.
- **Tipagem estática:** Código seguro e tipado usando interfaces do TypeScript.
- **Segurança:** Uso de variáveis de ambiente (`.env`) para proteger chaves de API.
- **Execução rápida:** Utilização do `tsx` para execução direta do código TypeScript.

---

## 🛠️ Tecnologias Utilizadas

- [Dotenv](https://www.npmjs.com/package/dotenv)

---

## 📋 Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior).
- Uma chave de API gratuita obtida na [ExchangeRate-API](https://www.exchangerate-api.com/).
